# 📝 Python Quiz Generator

A Quiz Generator application developed using Python that provides an interactive way to take quizzes and receive instant feedback.

## Features
- Interactive quiz interface
- Multiple-choice questions
- Automatic score calculation
- Instant feedback on answers
- Simple and user-friendly design

## Technologies Used
- Python

## Purpose
This project was developed to strengthen my Python programming skills by implementing core programming concepts such as functions, conditional statements, loops, and user interaction while building an educational application.
